2. 合法子网掩码判断
规则：连续1 + 连续0，禁止全0/全1/0后接1
```cpp
bool check(string s){
    bool zero = 0;
    for(char c : s){
        if(c == '0') zero = 1;
        else if(zero) return 0;
    }
    return s != string(8,'1') && s != string(8,'0');
}
```
