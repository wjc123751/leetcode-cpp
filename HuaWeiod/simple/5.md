1. 截取文件名最后16位
```cpp
if(fileName.size()>16)
  fileName=fileName.substr(fileName.size()-16);
```

2. 路径提取文件名
```cpp
int pos=path.find_last_of('\\');
fileName=path.substr(pos+1);
```

3. 组合唯一key
```cpp
string key=fileName+"_"+to_string(row);
```

4. 哈希表统计计数
```cpp
unordered_map<string,int> mp;
mp[key]++;
// 不存在：mp.find(key)==mp.end()
```

5. 最长递增子序列（合唱队DP）
```cpp
for(int i=0;i<n;i++)
  for(int j=0;j<i;j++)
    if(a[j]<a[i])
      dp[i]=max(dp[i],dp[j]+1);
```

6. 素数判断（标准模板）
```cpp
bool isPrime(int num){
  if(num<=1)return 0;
  if(num==2)return 1;
  for(int i=2;i*i<=num;i++)
    if(num%i==0)return 0;
  return 1;
}
```

7. 高频API
string：substr、find、find_last_of、size、to_string
unordered_map：mp[key]、find、end

8. 核心结论
截取后缀：s.substr(s.size()-n)
组合去重：a+"_"+b
哈希统计：mp[key]++
迭代器转下标：it-v.begin()
局部变量必须初始化
字符串：先去重后排序
素数伴侣：贪心不行，用匈牙利算法
蛇形矩阵：暴力模拟
